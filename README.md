# JavaScript Basics — Day 1 🚀

A short, hands-on introduction to JavaScript fundamentals. This document covers what JavaScript is, how to set up a local development environment, run your first script, and practice with variables, data types, and operators.

---

## Agenda (Day 1) ✅

1. **What is JavaScript & where it runs** — Overview of the language and runtime environments (browser, Node.js).
2. **Install Node.js & npm** — Verify installation and basic usage.
3. **Run your first JavaScript file** — Create and execute a simple script using the terminal.
4. **Variables & Data Types** — Primitive types, `let`/`const`, and variable usage.
5. **Operators** — Arithmetic, comparison, and logical operators.
6. **Hands-on practice** — Small exercises to reinforce concepts.

---

## Prerequisites ⚙️

- A modern code editor (e.g., **VS Code**).
- Node.js and npm installed. Verify with:

```bash
node -v
npm -v
```

- Basic familiarity with the terminal/command prompt.

---

## Quick Start — Setup & Run 🔧

1. Create a project folder and initialize npm (optional):

```bash
mkdir js-basics
cd js-basics
npm init -y
```

2. Create `index.js` with a simple example:

```js
// index.js
console.log('Hello, JavaScript!');
```

3. Run the script:

```bash
node index.js
```

---

## Hands-on Exercises ✍️

- Write a script that declares variables of different types and logs their values and types.
- Implement simple arithmetic expressions and print results.
- Create a small function that takes input and returns a computed value.

### Folder Structure

Each day folder (e.g., `01_Day_Introduction/`, `02_Day_Data_types/`) contains:

```
day-folder/
├── README.md or [day_number]_day_[topic].md  (Complete documentation)
├── [day_number]_day_starter/
│   ├── index.html
│   ├── scripts/
│   │   └── main.js
│   └── data/ (if applicable)
├── Other exercise files (.js files with examples and solutions)

```

### How to Use This Curriculum

1. **Read the Documentation** — Each day starts with theory and concepts in the markdown file.
2. **Review Starter Files** — Check the starter folder for example code structure.
3. **Complete Exercises** — Practice exercises are included in each day's markdown file (Level 1, 2, 3).
4. **Run Code** — Use Node.js to execute JavaScript files:
   ```bash
   node 01_Day_Introduction/01_day_starter/scripts/main.js
   ```
5. **Progress Sequentially** — Build knowledge incrementally from Day 1 to Day 20.

### Quick Navigation

All 20 days are located in the `js-basics/` folder. Start with:
```bash
cd js-basics
# Review Day 1
cat 01_Day_Introduction/01_day_introduction.md
# Run Day 1 example
node 01_Day_Introduction/01_day_starter/scripts/main.js
```
